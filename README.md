# Screen-Overlay-MacOS
A full screen overlay for meeting reminders and work blocks scheduling, designed for ADHD users, with aesthetic customization to add moodboards/images and text for motivation..

Setup Instructions:
Run brew install --cask hammerspoon, open it, and allow what it asks for.

Put init.lua in ~/.hammerspoon/. If you already have an init.lua there, rename to now_overlay.lua and add require("now_overlay") to yours.
Terminal command: mkdir -p ~/.hammerspoon && mv -i ~/Downloads/init.lua ~/.hammerspoon/init.lua

Click the hammer icon in the menu bar → Reload Config.
Press ⌃⌥⌘N to set your task and step, then ⌃⌥⌘T to test.
